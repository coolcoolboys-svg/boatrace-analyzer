# 開発者支援のアプリ内課金

App Store Connect に以下の消耗型アプリ内課金商品を作成する。日本の基準価格は税込の利用者支払額。価格はストア上で設定し、アプリは StoreKit から表示名と価格を取得する。

| 商品 ID | 日本での設定予定価格 |
| --- | --- |
| jp.boatraceanalyzer.support.small | 100円 |
| jp.boatraceanalyzer.support.medium | 500円 |
| jp.boatraceanalyzer.support.large | 1,000円 |

任意の都度購入であり、サブスクリプションではない。複数回の購入が可能。支援による機能差は設けない。商品作成・価格設定・審査・購入検証は別途必要。
