2023年5月から2025年の抽出日9,673レースで学習、2026年1〜8月2,503レースで号艇別係数の正則化を選択、9〜10月624レースで比較。各月1日・15日の抽出で全レースではない。2026年9〜10月はv5.0ですでに評価した期間であり、完全に新しい未観測期間ではない。元データの遡及訂正を排除できない。
