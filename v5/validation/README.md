# 予測モデルの検証（試験版）

2026-11-04 時点に Boatrace OpenAPI の programs / previews / results v3 を取得。2023年5月〜2026年10月の各月1日・15日の84日を抽出し、出走表・展示・単一の3連単結果を結合しました。取消・同着・欠損等の対象外を除き、12,800レースを使用。全開催日の検証ではありません。選択日の取り込み失敗は0日です。

- 学習：2023年5月〜2025年12月の64日、9,673レース。
- 係数調整：2026年1月〜8月の16日、2,503レース。
- 最終テスト：2026年9月〜10月の4日、624レース。
- 評価：v4.2相当の等級・全国2連対率・モーター2連対率・平均ST・展示タイムの同条件。3連単120通りの対数損失（小さいほど良い）、確率上位10通りへの結果包含率。オッズ条件を使った最大10通りの的中率や回収率ではありません。

| 期間 | モデル | 対数損失 | 確率上位10通り |
| --- | --- | ---: | ---: |
| 調整期間 | v4.2相当 | 4.0804 | 44.55% |
| 調整期間 | 学習モデル | 3.9745 | 47.74% |
| 最終テスト | v4.2相当 | 4.0105 | 46.47% |
| 最終テスト | 学習モデル | 3.8882 | 47.76% |

展示前の予測、選手別コース実績の手入力、資金回収率、全日・全場の均等な精度は検証していません。展開対象の直前データは事後に公開データから取得したもので、締切前の保存時点を保証できず、遡及訂正による情報混入の可能性があります。損失の差が小さいことやサンプル選択による偏りにも注意が必要です。

`collect_boat.py` と `train_boat.py` を同じディレクトリに置き、Python で前者、NumPy/SciPy を導入後に後者を実行すると同じ抽出・学習手順を再現できます。提供元が過去データを修正した場合は結果が変わります。配信元: https://github.com/boatraceopenapi/programs 、 https://github.com/boatraceopenapi/previews 、 https://github.com/boatraceopenapi/results 。
