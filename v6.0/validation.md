# v6.0 validation

号艇順をコースとして扱う。出走表・直前情報のみ使用し、レース結果や実進入は特徴量に使用しない。個人コース別成績の手入力部分は未検証。

2023年5月〜2025年の各月1日・15日、9,673レースで学習。2026年1〜8月の各月1日・15日、2,503レースで候補の選択。2026年9〜10月の各月1日・15日の624レースは過去にも評価した期間。選択した全追加項目モデルは、従来303/624、新モデル300/624。追加検証として選択を固定した後、2026年10月16〜31日の2,426レースで従来1123/2426=46.29%、新モデル1149/2426=47.36%。指標はオッズ抜きの確率上位10通り。統計的有意性は未検証。過去日データは事後訂正の可能性があり、締切前に実際に取得できた値とは限らない。

追加の候補は当地勝率・2連率・3連率、全国勝率・3連率、モーター3連率、ボート2・3連率、F・L回数、年齢、体重、展示ST、展示F、チルト、調整重量、風速・波高と号艇の組み合わせ。欠損は中立。オリジナル展示、選手別コース成績、直近成績、時点保証された予測前スナップショットは追加学習されていない。データ利用はBoatrace OpenAPI (非公式)。
